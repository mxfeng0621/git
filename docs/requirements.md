# 需求文档

## 1. 游戏世界观

### 1.1 背景设定

大陆名 **艾尔德拉**（Eldra），中古奇幻世界。诸神沉寂千年后，龙族从东方山脉苏醒，阴影笼罩大陆。玩家作为一名冒险者，从边境小镇出发，逐步揭开龙族苏醒背后的阴谋。

### 1.2 核心场景

| 章节 | 场景 | 等级区间 | 关键要素 |
|------|------|----------|----------|
| 序章 | 河畔镇（新手村） | 1-3 | 教程、初始装备、第一个伙伴 |
| 第一章 | 幽暗森林 | 3-6 | 地精营地、精灵遗迹、支线探索 |
| 第二章 | 废弃矿洞 | 6-9 | 矮人宝藏、地下种族、机关陷阱 |
| 第三章 | 黑石城堡 | 9-14 | 亡灵军团、吸血鬼领主、势力选择 |
| 终章 | 龙脊山脉·龙巢 | 14-20 | 远古巨龙、最终抉择、多结局 |

### 1.3 主要势力

- **王国联军** — 人类主导的秩序阵营，守护边疆
- **精灵议会** — 隐居森林的古老人种，掌握上古知识
- **矮人铁盟** — 山中之民，锻造与符文大师
- **影月教团** — 崇拜龙神的邪恶组织，推动龙族苏醒
- **自由都市** — 中立贸易城邦，情报与黑市

## 2. 队伍系统

玩家率领一支 **4人冒险小队** 探索地牢。其中主角由玩家自定义创建，其余3人通过剧情招募或在酒馆雇佣。

### 2.1 基础属性（六维）与购点制

| 属性 | 英文 | 影响 |
|------|------|------|
| 力量 | STR | 近战物理伤害 |
| 敏捷 | DEX | 远程伤害、闪避率、行动顺序 |
| 体质 | CON | 生命值上限、防御力 |
| 智力 | INT | 法术伤害、法术暴击率 |
| 感知 | WIS | 魔法值上限、治疗强度 |
| 魅力 | CHA | 交易价格、说服成功率 |

**D&D标准购点制**（27点，全部从8起步）：

| 属性值 | 8→9 | 9→10 | 10→11 | 11→12 | 12→13 | 13→14 | 14→15 |
|--------|-----|------|-------|-------|-------|-------|-------|
| 花费 | 1点 | 1点 | 1点 | 1点 | 1点 | 2点 | 2点 |

单项最高15（不含种族加成），从8拉到15共需 **9点**。

**配点示例**：
- 战士：力量15(9) 敏捷12(4) 体质14(7) 智力8(0) 感知10(2) 魅力13(5) = 27
- 法师：力量8(0) 敏捷12(4) 体质13(5) 智力15(9) 感知12(4) 魅力13(5) = 27
- 盗贼：力量10(2) 敏捷15(9) 体质12(4) 智力10(2) 感知12(4) 魅力14(7) = 28（需回调1点）

### 2.3 种族与天赋

每个种族提供：属性加成 + 1个主动技能 + 2个被动特质。

**人类**
- 属性：全属性+1
- 主动：**逆境求生** — 战斗中使用，本回合闪避率+20%，每场战斗限1次
- 被动①：**多才多艺** — 经验获取+5%
- 被动②：**外交手腕** — 商店买卖价格优惠5%

**精灵**
- 属性：DEX+2, INT+1
- 主动：**精灵之眼** — 探索中使用，揭示当前场景所有隐藏物品和陷阱
- 被动①：**敏锐感知** — 先手值+2
- 被动②：**森林之友** — 森林场景战斗时全队命中率+5%

**矮人**
- 属性：CON+2, STR+1
- 主动：**石之坚韧** — 战斗中使用，获得最大HP 20%的护盾，持续2回合
- 被动①：**毒素抗性** — 毒伤害减免30%
- 被动②：**矿洞直觉** — 矿洞/地下场景不迷路，额外发现稀有矿石

**半身人**
- 属性：DEX+2, CHA+1
- 主动：**幸运硬币** — 战斗中使用，下次受击时50%概率完全闪避
- 被动①：**小幸运** — 闪避率+5%
- 被动②：**投掷专精** — 使用投掷类道具时伤害+30%

### 2.4 队伍构成

- **主角** — 玩家创建，自定义姓名/种族/职业/属性，不可离队
- **同伴** — 通过剧情或酒馆招募，最多携带3人同行，超出者留宿酒馆
- 酒馆可随时调整队伍阵容
- 每人独立经验值，参战队员获得经验，酒馆待命者不获得

### 2.5 等级与经验

- 等级范围：1-20
- 升到下一级所需经验：`XP_needed = level × 1000`
- 每级HP/MP上限自动成长（取决于职业成长值）
- 每级获得 **2点自由属性** 可分配到六维
- 升级时HP/MP回满
- 技能按固定升级表自动解锁，无需选择

## 3. 交互机制

### 3.1 命令系统

支持中文指令，大小写不敏感，支持别名。玩家可通过底部输入框键入命令，也可点击快捷按钮。

**移动类**
```
前往 森林          — 移动到已知地点
返回               — 回到上一场景
地图               — 查看世界地图
```

**战斗类（手动干预）**
```
策略               — 调整全队战斗策略
策略 战士 全力     — 调整某人策略
集火 地精B         — 全员优先攻击该目标
使用 治疗药水 战士 — 手动对某人使用道具
逃跑               — 尝试脱离战斗
```

**交互类**
```
探索               — 搜索当前场景（可能发现隐藏物品/陷阱）
对话 铁匠          — 与NPC对话
检查 宝箱          — 检视物品
拾取 长剑          — 拾取地上物品
```

**物品类**
```
背包               — 打开背包
装备 铁盾          — 装备物品
使用 治疗药水      — 使用消耗品
丢弃 破布衣        — 丢弃物品
```

**信息类**
```
状态               — 查看角色详情
任务               — 查看任务日志
帮助               — 显示可用命令列表
```

### 3.2 快捷按钮

界面右侧常驻按钮栏，根据当前场景上下文动态显示可用操作：
- 战斗场景：攻击 / 施法 / 防御 / 逃跑 / 使用道具
- 探索场景：探索 / 对话 / 检查 / 前往 / 休息
- 城镇场景：商店 / 铁匠 / 酒馆 / 任务板 / 离开

### 3.3 NPC对话树

- 每个NPC有独立对话树，包含：问候语、关键信息、任务触发、重复对话
- 对话选项影响好感度，好感度影响商店折扣、任务解锁
- 对话中可随时 `离开` 退出

## 4. 战斗系统（策略指令 + 条件规则）

### 4.1 核心理念

战斗**自动展开**，玩家不逐回合微操。战前为每人设定策略，战中观察局势并随时调整策略或手动使用道具。战斗规则轻量、直观，不模拟完整DND检定。

### 4.2 战前 → 策略设定

开战瞬间弹出策略面板，为每位队员选择**战斗策略**：

| 策略 | 行为 |
|------|------|
| **全力猛攻** | 优先使用最强技能，不保留法力，快速结束战斗 |
| **平衡输出** | 普攻与技能交替，法力低于30%时转为节省 |
| **保留法力** | 仅用普攻/远程攻击，不使用法术，适合小怪战 |
| **优先治疗** | 队友HP低于60%时施放治疗，否则普攻 |
| **防御牵制** | 使用嘲讽/盾墙/闪避，承担伤害保护队友 |

玩家可在此界面修改默认策略，也可直接确认开战。

### 4.3 战中 → 自动回合 + 手动干预

每回合自动展开，战斗日志实时滚动：

```
━━━━ 第 3 回合 ━━━━
战士[全力]  猛击 → 地精A，-28HP ✓击杀
盗贼[全力]  暗影步 → 地精B，背刺判定！-35HP
法师[保留]  魔杖射击 → 地精C，-9HP
地精C      攻击 → 战士，-0HP（格挡）
地精B      攻击 → 盗贼，-12HP
牧师[治疗]  治愈之光 → 盗贼，+18HP
```

战斗中玩家随时可以：
- **切换策略** — 右键点击某人，重新选择策略
- **手动操作** — 输入 `使用 治疗药水 战士` 直接使用道具
- **集中攻击** — 输入 `集火 地精B` 全员优先攻击该目标
- **撤退** — 输入 `逃跑` 尝试脱离战斗

### 4.4 条件规则（战前预设，持久生效）

在设置/角色面板中为每人预设**自动触发规则**，战斗中满足条件自动执行：

| 规则类型 | 条件 | 动作 |
|----------|------|------|
| 自保喝药 | 自身HP < 30% | 自动使用背包中的治疗药水（优先低级药水） |
| 急救队友 | 任一队友HP < 20% | 牧师优先施放单体治疗 |
| 法力红线 | 自身MP < 10% | 切换为"保留法力"策略 |
| 优先击杀 | 场上有HP<15%的敌人 | 全员优先补刀 |
| Boss爆发 | 出现Boss级敌人 | 法师使用最强法术 |
| 群体治疗 | 3人以上HP < 50% | 牧师施放群体治疗 |

每项规则可开启/关闭，阈值可调。规则由引擎每回合自动检查，优先级高于当前策略。

### 4.5 伤害计算（简化）

摒弃DND完整检定链，使用简化公式：

```
物理伤害 = 武器基础伤害 + 力量/敏捷修正
法术伤害 = 法术基础伤害 + 智力修正
暴击率   = 敏捷/智力提供（物理/法术各5%基础 + 修正）
闪避率   = 敏捷修正
减免     = 体质修正 + 装备护甲值
最终伤害 = (输出伤害 × (1 - 闪避率?1:0) - 减免)，最小为1
```

### 4.6 怪物AI

| 类型 | 行为 |
|------|------|
| 野兽 | 攻击当前HP最低者 |
| 人形 | 围攻最前排目标，HP<30%逃跑 |
| 亡灵 | 攻击最近的，无视恐惧 |
| Boss | 半血换阶段，使用AOE技能 |

### 4.7 战斗结束

- **胜利** — 所有怪物HP=0，获得经验/金币/掉落物
- **全灭** — 全队HP=0，自动读取最近存档
- **撤退成功** — 返回上一场景，无奖励，怪物重置
- **战后HP/MP保留** — 不自动恢复，需要休息或使用道具

## 5. 任务与成长

### 5.1 任务类型

- **主线任务** — 推进剧情，解锁新场景，不可跳过
- **支线任务** — 可选，提供额外奖励和剧情补充
- **悬赏任务** — 重复可刷，击杀指定怪物/收集物品
- **职业任务** — 各职业专属，解锁职业特有技能/装备

### 5.2 奖励体系

| 奖励类型 | 来源 |
|----------|------|
| 经验值 | 战斗、完成任务、探索新场景 |
| 金币 | 战利品、任务报酬、出售物品 |
| 装备 | Boss掉落、商店购买、任务奖励、宝箱 |
| 道具 | 采集、购买、任务奖励 |
| 声望 | 完成势力相关任务，解锁特殊商店/剧情 |

### 5.3 装备系统

- 稀有度：**普通（白）→ 精良（绿）→ 稀有（蓝）→ 史诗（紫）→ 传说（橙）**
- 部位：武器、副手、头盔、护甲、手套、靴子、饰品×2
- 武器类型决定伤害骰（匕首d4↔巨剑2d6）
- 防具提供AC加成，重甲限制敏捷修正

### 5.4 消耗品

药水（治疗/法力/力量/敏捷等）、卷轴（一次性法术）、投掷物（匕首/炸弹）、食物（休息加成）、钥匙/任务物品

- **商店界面** — 物品列表+价格，支持买卖
- **战斗界面** — 上方怪物信息，中央动画区，下方行动选择

## 7. 存档系统

### 7.1 存档位

- 5个手动存档位 + 1个自动存档位
- 自动存档时机：切换场景、战斗开始前、完成任务后
- 显示信息：角色名、等级、所在场景、游戏时长、时间戳

### 7.2 存档数据范围

| 数据 | 内容 |
|------|------|
| 角色 | 所有属性、等级、经验、装备、背包、已知法术 |
| 进度 | 当前场景、已完成任务、剧情标记 |
| 世界 | 已击败Boss、已开启宝箱、NPC好感度 |
| 元数据 | 游戏时间、存档时间、版本号 |

## 8. AI插图预留

- 每个场景定义 `scene_id`，对应一张插图
- 当前版本使用本地预设图片（`assets/images/scenes/`）

- 插图在场景视图中置顶展示，无图片时显示文字描述
