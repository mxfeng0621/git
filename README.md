# 龙焰传说 — DND文字冒险游戏

基于龙与地下城（D&D）规则的桌面文字冒险游戏，采用 PySide6 构建精美的 Windows 桌面应用。

## 特色

- **经典D&D规则** — 六大属性、多职业、多种族、D20骰子检定
- **混合交互** — 图形界面操作 + 自由文本指令输入，兼顾便捷与沉浸感
- **回合制战斗** — 战术选择、技能法术、暴击闪避，策略深度
- **丰富剧情** — 主线任务链 + 支线任务，从新手村到龙巢的完整冒险
- **本地存档** — SQLite 存储，多存档位，随时继续冒险
- **AI插图预留** — 架构已预留 AI 图片生成接口，未来可实时生成场景插图

## 技术栈

Python 3.11+ / PySide6 / SQLite

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 启动游戏
python src/main.py
```

> Windows 用户可直接运行打包后的 `龙焰传说.exe`
